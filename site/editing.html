Publish a project file

Keep the file in its original Google Drive location. Use the catalogue to link to it and record its revision and issue status.

Open Project Resources Google Sheet ↗

Record issue status and confirm the link

  1. Enter the original Drive file link and the correct project, title, version and file type.
  2. Record the current issue or approval status, including when it is unverified.
  3. Set Publish to TRUE after the document owner clears the link for listing. Confirm the original Drive link and its access record.

The document appears after a successful Pages refresh. Readers still need permission to open a restricted Drive file.
