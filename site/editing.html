Publish a project file

Keep the finalized file in its original Google Drive location. Use the catalogue to link to that file and record the approved version.

Open Project Resources Google Sheet ↗

Record approval and confirm the link

  1. Enter the original Drive file link and the correct project, title, version and file type.
  2. Use the existing approval field to record the confirmed final status, such as Approved, Issued or Signed.
  3. Set Publish to TRUE after the document owner confirms the issue and link. Review the existing Drive access and readback record.

The document appears after a successful Pages refresh. Readers still need permission to open a restricted Drive file.
