03 / ORIGINAL DOCUMENTS

Where are the original PDF and DWG files?

They are in the project’s Google Drive folders, not inside the website. Some original drawing sets contain several disciplines in one PDF. A file can appear under more than one heading without creating a second copy.

Before construction: check the original title block, revision, issue date and engineering approval. A file being listed here is not evidence that it is the latest approved version.

Browse project files →

Which page should I use?

All Projects for project names and links; Drawings & Files for grouped plans and reports; Field Records for site work; Google Sheets for the full staff workbook directory.

04 / WEBSITE UPDATES

When will my change appear?

  1. Edit the correct original Sheet and keep its Drive file link.
  2. Save the change and make sure its original document and revision information are correct.
  3. The website's normal publishing process checks the information and refreshes the online file list. It generally runs hourly and may be delayed.
  4. Reopen the project page and check the displayed file before sharing it.

Changes to the website design itself are handled separately by its maintainers.

05 / EARLIER VERSIONS

What happens to older drawings and Sheets?

Older original files should remain in their project Drive folders or version-history collection. New links must not silently replace approved historic agreements or drawings. The Project Resources Sheet has preserved earlier copies in the same established version-history folder.
