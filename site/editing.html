Find a project or record

All Projects is the project directory. Desk Resources is the single detailed file gallery. Project Intake opens permanent project and personal journals.

Where the originals stay

01_JP Drive holds company and project originals. The catalogue is a link register; missing listings do not establish missing original files.

Record issue status and confirm the link

  1. Enter the original Drive file link and the correct project, title, version and file type.
  2. Record the current issue or approval status, including when it is unverified.
  3. Set Publish to TRUE after the document owner clears the link for listing. Confirm the original Drive link and its access record.

The document appears after a successful Pages refresh. Readers still need permission to open a restricted Drive file.

How updates work

The authenticated Actions publisher validates the approved source records and publishes a read-only projection. Refreshes are scheduled hourly, but a completed deployment is required for visibility. Catalogue receipts do not certify the latest original revision or permissions for every reader. Confirm drawings with the issuing engineer.

Older versions

Historical and superseded originals remain in Drive. Earlier Project Resources versions. Do not assume a newer copy is approved.
