ABOUT THE LIBRARY

Find your files. Know where they belong.

Drawings, models and reports remain in their original Google Drive folders. This website helps you find them; it is not another copy of your project files.

3. How does a website update happen?

  1. You update the original approved Google Sheet or drawing in its existing Drive location.
  2. The website's publishing process checks whether the document list can be updated safely.
  3. When those checks succeed, the website shows the current list of available links. Publishing typically runs hourly, but changes may take longer.
  4. The site engineer still confirms the latest issued drawing before construction.

The website's automatic checks help prevent broken links and missing files, but they do not approve a drawing or replace an engineer’s signature.

4. What about old, duplicate or superseded drawings?

Historical source files are preserved in Google Drive. Several drawing sets have multiple versions or similarly named files. A new copy does not automatically become the approved one. Previously copied project files and their older original sources should remain available until the document owner confirms the revision history.
