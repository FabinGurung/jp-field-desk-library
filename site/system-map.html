2. GitHub Actions — the actual job tree

The main workflow runs at minute 37 each hour (UTC) and also on qualifying pushes, pull requests and manual dispatch. A successful Sheet edit alone does not trigger a real-time push. Historical release jobs are not new source consumers.

resource-library-pages.yml — main publication and QA
  1. test — JavaScript syntax, Python unit tests, synthetic public artifacts
  2. browser-qa — Chromium desktop/mobile on PR and pushes (skipped for schedule)
  3. project — authorized read-only Google Sheets identity; source-led Desk catalogue, approved historical Payment, public canonical project names if accessible
  4. deploy — publish validated GitHub Pages artifact
  5. scheduled-refresh-assert — require successful scheduled build and deployed Pages
  6. release-cutover — historically gated v1.3.2 release
  7. release-astam-v1-4 — Astam v1.4.0 source/readback milestone
  8. release-workspaces-v1-5 — v1.5.0 compatibility milestone
  9. release-desk-field-v1-6 — Desk/Field split release
  10. release-clean-payment-v1-7 — historical Payment projection release
  11. release-scheduled-refresh-v1-7-1 — refresh verification
  12. release-staff-sheets-v1-8 — original staff Sheets directory
  13. release-desk-source-v1-8-1 — source-link reconciliation
  14. release-resource-ux-v1-9 — shared UI and Estimation ownership
Separate QA / historical-migration workflows
  • a9-gated-preview-qa.yml — preview history gate
  • a9-provider-inventory-qa.yml — provider inventory integrity
  • a9-history-transfer-qa.yml — migration preservation QA
  • a9-history-transfer.yml — controlled history transfer (not ordinary web publishing)
Source publisher scripts and outputs

scripts/sheets_read.py performs read-only authenticated double reads. scripts/publish_library.py validates original Drive references and writes catalog.json, document-packets.json. scripts/publish_field_payments.py owns the separate 958-row historical Payment projection. scripts/publish_project_directory.py generates projects-directory.json from canonical public project identities, or marks its dated fallback explicitly if that Sheet's reader has no access.

All source evidence remains in Google Drive; generated JSON is derived presentation data, not an editable register.

Storage policy: prefer GitHub commit history and lightweight markdown/JSON manifests for code and navigation history; preserve originals and sensitive evidence in restricted Drive. Copying code to Drive does not replace verified Git ancestry, and deleting old code prematurely can break reproducibility.
