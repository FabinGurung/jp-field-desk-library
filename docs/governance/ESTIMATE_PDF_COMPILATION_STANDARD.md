# Estimate PDF compilation standard

The authoritative editable formatting and QA standard is the [JP Estimate PDF Compilation Standard — V000001](https://docs.google.com/document/d/1gFM7XkY-G57UEbzDQMQ-2rCiYsCWHIxBxq22xGD3JMM/edit). Read the current version before compiling construction estimate PDFs. The original Google Sheets/Excel sources remain authoritative for quantities, rates and amounts. This repository publishes verified catalogue hyperlinks only; it does not own estimate calculations or font binaries.

The existing resource-library-pages workflow reads the owner register and source readback, validates the link catalogue and deploys it. No client documents are copied into GitHub. Superseded PDF entries remain in Drive history and are excluded from the current catalogue.

When a replacement workbook is received, preserve it byte-for-byte, archive the superseded workbook and PDFs without deleting them, and publish only the latest verified workbook and PDF links from the owner register.
